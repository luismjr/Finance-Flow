Quality Gate Strategy
Every pipeline stage enforces data quality via dbt tests before data reaches downstream consumers:
Staging layer — not_null, unique, accepted_values, positive_price, high_gte_low on raw ingested data.
Mart layer — not_null, unique, relationship, range_check, not_negative on transformed metrics.
Any test failure blocks the DAG and triggers an alert — preventing corrupt data from reaching the Looker Studio dashboard.
